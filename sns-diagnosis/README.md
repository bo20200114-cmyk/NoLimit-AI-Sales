# SNSアカウント無料診断フォーム

Googleマイビジネスへの掲載を予定・検討している新規クライアント向けの、SNSアカウント無料診断
のランディングページ＋申し込みフォーム。ビルド不要の静的サイトです。

## 構成

```
index.html   ページ全体のマークアップ（ヒーロー / 診断内容 / 利用の流れ / 対象者 / 申し込みフォーム / FAQ）
styles.css   スタイル一式（レスポンシブ対応）
script.js    フォームのクライアントサイドバリデーションと送信後の完了表示
```

## フォームの項目

- 会社・店舗名 / ご担当者名 / メールアドレス（必須）、電話番号（任意）
- 業種（必須）
- Googleマイビジネスの掲載状況（必須・単一選択）
- 診断を希望するSNS（必須・複数選択）とアカウントURL・ID
- 現在の課題・お悩み（任意・複数選択）、その他ご要望（任意）
- 診断結果の受け取り方法（必須・単一選択）
- プライバシーポリシーへの同意（必須）

未入力・不正な項目があれば項目ごとにエラーメッセージを表示し、最初のエラー項目にフォーカスします。
すべて満たすと送信完了メッセージに切り替わります。

## 本番導入時にやること

このサンプルには送信先バックエンドがありません（`script.js` 内で `console.log` するのみ）。
実運用では `script.js` の送信処理を、実際のフォーム送信先（自社API / Google Apps Script /
CRMのWebhookなど）への `fetch` 呼び出しに差し替えてください。また `index.html` 内の
プライバシーポリシー欄（`#privacy`）を実際の事業者情報に合わせて更新してください。

## 動作確認

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```
